## Implementation notes

- `rquickjs 0.14.0` with `std,array-buffer,bindgen`.
- Android has no prebuilt aarch64 binding in `rquickjs-sys`; `bindgen` is required.
- NDK r27c supplies libclang at `toolchains/llvm/prebuilt/linux-x86_64/musl/lib`; CI sets `LIBCLANG_PATH` accordingly.
- QuickJS needs an 8 MiB stack for the current 2.7 MiB player script; the default 256 KiB stack raised `Exception generated by QuickJS`.
- Runtime sandbox: no host functions, 256 MiB memory limit, 30 s deadline.
- `cargo ndk -t arm64-v8a -t x86_64 -P 26 check -p streamtube-core --locked` passed after enabling bindgen.
